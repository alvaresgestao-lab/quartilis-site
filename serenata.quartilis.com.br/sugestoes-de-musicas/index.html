Sugestões de músicas

Como escolher as músicas para a serenata?

A idéia é que seja um presente personalizado, então cada serenata deve ser única, considerando o gosto musical do homenageado. Tente pesquisar quais as músicas preferidas e converse conosco. Será um prazer fazer uma versão especial para a serenata. Estamos a disposição também para sugerir músicas e orientar qual o melhor repertório para os instrumentos escolhidos.

Mas, se você quer se inspirar e ter algumas idéias, segue uma lista das músicas mais tocadas nas nossas Serenatas em Curitiba:
